- 規則:
  1. 監聽列＝TCP、本地埠相符(以最後一個冒號切出之埠字串完全相等,不用 endsWith)、遠端位址為萬用位址(`0.0.0.0`、`::`、`[::]`、`*`)且遠端埠為 0(或 `*`)、PID 為大於 0 之安全整數;**不依狀態欄**(狀態值可能錯、狀態文字隨語系、可能缺欄).netstat 之欄位取第 1 欄協定、第 2 欄本地、第 3 欄遠端、最後一欄 PID;本埠之監聽列而 PID 欄非數字者整份 netstat 輸出視為無法解析(轉查備援,不靜默略過而得部分結果).**僅綁定未監聽(bind 後未 listen)之 socket(wu312,2026-11-05 實測更正)**: 同樣佔用該埠,但 netstat 與 OS API(GetExtendedTcpTable)不列,只有退回路徑之 Get-NetTCPConnection 列(見〈已知限制〉);規則 1 之判定不變(遠端為萬用位址且遠端埠 0),被列到的才成立.
  2.   4. Linux／macOS: `lsof -nP -iTCP:<埠> -sTCP:LISTEN -t`;離開碼 0 與 1(查無)為正常,其餘失敗;輸出含非數字字詞為無法解析.
  5. 失敗與無人嚴格分開: 空陣列只代表已確認無人;無法啟動(含指令不存在)、逾時、非預期之離開碼(含因訊號結束)、輸出無法解析(netstat 無任何 TCP/UDP 列、PowerShell 缺標記或標記間有不合格之列、lsof 非數字)、注入之執行函數拋錯／reject／回傳不合、埠號不合法、opt 不可讀 → 非同步版 reject 字串、同步版回 null(訊息經 onTrace 之 settle 事件 `msg`);兩版之訊息相同.
  6. 每個子指令帶時限(`opt.timeout`,預設 10000ms,非正數為預設,小數無條件進位為整數〔spawnSync 之 timeout 非整數即拋 ERR_OUT_OF_RANGE〕,夾至計時器上限)、`windowsHide: true`、不經 shell、stdin 不開啟;逾時或 stdout 逾 64MB 即強制結束子指令(SIGKILL;netstat 與 powershell 不另建子程序)並視為失敗(非截斷).同步版以 `spawnSync` 之 `timeout`/`killSignal`/`maxBuffer`.非同步版之預設執行函數: `error` 監聽先於存取 stdio;stdout/stderr 之串流 `error` 轉為失敗結果;一律先落定(done)再 kill(`child.kill` 失敗時 node 同步發出 `error`,其處理器見已落定即返回,不遞迴).
  7. 執行函數可注入(`opt.exec`,與 spawnSync 同形之 `{ status, stdout, error }`;非同步版可回 Promise;同步版回 Promise 視為失敗並先標記其 rejection 已處理).`opt.platform` 供測試走 lsof 路徑.
