### 規則

1. **判定**:實數參數 `isenum(v, chk)`、整數參數 `iseint(v, chk)`;計時毫秒 `{ use:'timer', gt:0 }`(原 `ispint`／正數者)或 `{ use:'timer' }`(原 `isp0int`／允許 0 者);個數、長度 `iseint { use:'count', min:1 }`;位數 `{ use:'digits' }`;距離、尺寸 `isenum { use:'nonnegative' }`;隨機範圍之整數 `{ use:'safe' }`;**`setTimeoutHp`／`setIntervalHp` 之 `interval` 用 `isenum { use:'positive' }`(>0,不設上限,見規則 8)**.
2. **非預期一律視為未給**:`undefined`／`null`、非有效數字、超出範圍(含計時超過 2147483647、個數超過 4294967295)、`Infinity`、`'0x10'`、`'1e400'`、包裝物件 `new Number(5)`、BigInt、布林、物件等 → 回傳該參數之預設,**不報錯、不夾限**.
3. **取值(K4)**:有效則 `Number(v)`(去頭尾空白後轉數字),其後只用轉換值;**不再用 `cint`／`cdbl`**;計時毫秒可帶小數、不取整(執行環境本會截斷).**例外**:值交給要求整數之下游者改用 `iseint`(小數屬非預期、改用預設,同修前 `ispint` 之行為)——`fsEvem`／`fsWatchFile` 之 `timeInterval`／`timeBinaryInterval`(交給 chokidar → `fs.watchFile` 須 uint32 整數,小數會使每個檔案回報 `ERR_OUT_OF_RANGE`;獨立審查者指出,測試 `optValG2fsWatch.test.mjs` 鎖定).
4. **共用內部模組 `src/_optVal.mjs`(單一擁有者)**:`optVal(v, def, rule, opt)`,`rule = { fn, name, kind:'enum'|'eint', chk, defDesc? }`,建議於模組層宣告一次;`opt` 為第 4 參數,供讀 `debug`／`funLog`(位置參數且函數沒有 opt 物件可帶 `debug` 者不傳 → 不警告).警告出口與去重表與 `isenum`／`iseint` 共用 `src/_numOpt.mjs` 之 `warnOnce`(去重鍵 `fn|invalid|參數名`,每行程一次,上限 256,`parseNumOpt.resetWarned()` 重設).
5. **`opt.debug`**(布林,非布林視為 false):`true` 時非預期另輸出警告 `[wsemi <函數名>] invalid <參數名>: must be <種類描述>, using default <預設>`;固定詞彙,**不含傳入之值**(K9、V20),預設值與範圍皆取自程式常數;出口為 `opt.funLog`(函數,以 `(msg, { fn, reason:'invalid', key })` 呼叫)否則 `console.warn`;出口拋錯一律忽略,**含出口(async 函數等)回傳之 rejected thenable**(否則成為 unhandledRejection 使行程崩潰;獨立審查者指出,`optValHardening.test.mjs` 鎖定;`isenum`／`iseint` 之 `warnOnce` 路徑同).未宣告之鍵不提示(V7:整份轉傳者屬常態;白名單屬選用,本批未做).
